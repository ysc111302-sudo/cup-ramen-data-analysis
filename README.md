# 컵라면, 비쌀수록 더 나을까?
### 웹 크롤링 기반 국내 컵라면 가격·영양성분 비교 분석

Firecrawl로 국내 5개 판매처에서 컵라면/용기면 데이터를 수집하고, 가격·중량·영양성분을
비교 분석하여 **인터랙티브 HTML 슬라이드 덱**(16:9)으로 정리한 데이터 스토리텔링 프로젝트입니다.

- 발표 자료(HTML): `index.html`
- 데이터: `data/cup_ramen.csv`, `data/analysis.json`
- 시각화: Chart.js (인터랙티브, 로컬 번들)

---

## 1. 프로젝트 주제

> “컵라면은 가격이 비쌀수록 양이 많고 영양도 좋을까?”

단순 순위 나열이 아니라, 실제 수집 데이터로 아래 질문에 답합니다.

1. 가격이 비쌀수록 양(중량)이 많은가?
2. 가격이 비쌀수록 열량·단백질도 높은가?
3. 브랜드별 평균 가격·나트륨에 차이가 있는가?
4. 중량이 큰 제품일수록 나트륨도 증가하는가?
5. 국물형과 볶음형의 영양성분 차이는?
6. 가격 대비 양이 많은(가성비) 제품의 특징은?

## 2. 데이터 수집 방법

- 도구: **Firecrawl** (`/v1/scrape`, `/v1/map`, `/v1/crawl`, `/v1/batch/scrape`, `/v1/search`)
- 수집 대상(5개 사이트)

| 브랜드 | 출처 | 비고 |
|---|---|---|
| 농심 | nongshimmall.com 컵라면 카테고리(5페이지) | 가격·중량 수집 |
| 삼양식품 | samyangfoods.co.kr 컵라면 카테고리 | 가격·중량 + 공식 영양정보 |
| 오뚜기 | otokimall.com 컵라면 카테고리 | 가격·중량 수집 |
| 팔도 | paldofood.co.kr 면 카테고리 | 공식 영양정보 |
| 컬리 | kurly.com | 가격 참고 |

- 수집 변수: 브랜드, 제품명, 중량(g), 판매가격, 묶음수량, 개당가격, 열량, 나트륨,
  탄수화물, 당류, 지방, 단백질, 소컵/큰컵, 국물형/볶음형, 출처 URL
- 원칙
  - **컵라면/용기면만** 포함하고 봉지라면·선물세트·굿즈는 제외
  - 동일 제품은 중복 제거
  - 묶음상품은 수량이 명확할 때만 개당가격 계산
  - 확인 불가 값은 임의 추정하지 않고 **null/빈칸** 처리
  - 모든 행에 원본 **출처 URL** 보존
  - 제조사 공식 페이지 영양정보를 쇼핑몰 정보보다 우선

수집 결과 원본은 루트의 `cup_ramen.csv`(전체 202행)에, 정제·분석용 데이터셋은
`data/cup_ramen.csv`(컵라면 40종)에 저장했습니다.

## 3. 데이터 정제 및 파생변수

`scrape/analyze.py`가 아래를 계산합니다.

- 100g당 가격 / 100g당 열량 / 100g당 나트륨
- 1,000원당 중량 / 1,000원당 단백질
- 브랜드별 평균 가격·열량·나트륨
- 국물형/볶음형 평균 영양성분
- 상관계수(Pearson): 가격×중량, 가격×열량, 중량×나트륨 등

**결측·이상치 처리**

- 결측: 농심·오뚜기 영양라벨이 이미지로만 제공되어 영양값 null (26개 변수 결측),
  팔도는 제조사 페이지라 가격·중량 null(8건).
- 이상치: 100g당 가격이 `Q3 + 1.5·IQR` 초과인 **삼양 큰컵 치즈불닭볶음면**을
  가격 이상치로 판단하여 브랜드 평균·상관분석에서 제외했습니다(사유는 `data/analysis.json`의 `outliers`에 기록).

## 4. 분석 방법

`data/cup_ramen.csv` / `data/analysis.json`을 기반으로:

- 브랜드별 평균 비교(가격, 100g당 가격, 나트륨)
- 가격×중량, 중량×나트륨 산점도 + 추세선
- 국물형 vs 볶음형 영양성분 비교
- 100g당 가격 랭킹

핵심 결과 요약

- 가격×중량 상관 **r = 0.41** (n=31) → 비싸다고 항상 양이 많지 않음
- 브랜드 평균 개당가격 1,353~1,550원으로 큰 차이 없음
- 100g당 가격은 최저 1,005원(삼양 큰컵 짜짜로니) ~ 최고 2,307원(농심 너구리컵) (**약 2.3배**)
- 나트륨: 국물형 1,612mg > 볶음형 1,230mg (팔도 1,516mg > 삼양 1,166mg)
- 중량×나트륨 상관 **r = 0.71** (n=5, 삼양) → 상관관계이며 인과관계 아님

## 5. 실행 방법

별도 빌드 없이 정적 파일로 동작합니다. 로컬에서 확인하려면:

```bash
# 저장소 루트에서
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

- **← → / Space / PageUp·PageDown**: 슬라이드 이동
- **Home / End**: 처음 / 마지막
- **F**: 전체화면 발표
- `index.html?static=1#5` 처럼 `static=1`을 붙이면 애니메이션 없이(스크린샷/인쇄용) 렌더링합니다.
