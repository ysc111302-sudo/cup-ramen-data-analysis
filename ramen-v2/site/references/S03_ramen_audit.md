# S03 컵라면 재계산 기록

재현: `python ramen-v2/tools/recalculate.py`

원본 CSV는 변경하지 않음. 판매가격 / 묶음수량의 반올림 전 값으로 파생변수·평균·Pearson r 계산. 표시 때만 반올림.
브랜드 평균 100g당 가격은 제품별 (판매가격 / 묶음수량 / 중량 × 100)의 단순 산술평균. 총가격/총중량 방식 아님.
원본 202행 → 사전 선정 목록의 컵라면 40종. 282건은 기존 스크립트에 하드코딩된 후보 수로 원본 행수와 다르므로 발표 수집 실적으로 사용하지 않음.
기존 제외 규칙 재현: 전체 가격 보유 32종, exclusive 사분위수 Q1=1314.2324, Q3=1893.1677, 상한=2761.5706원/100g.
큰컵 치즈불닭볶음면이 상한을 소폭 초과. 가격 오류라는 증거는 없음. 본 분석은 포함하고 제외 결과를 민감도 분석으로 병기.

## 확인되지 않은 원자료 정보
- 정확한 수집 일시 및 시간대. 파일 수정일로 수집일을 추정하지 않음.
- 할인·쿠폰·배송비 포함/제외 기준. 판매가격 필드만 사용했으며 편의점 실판매가를 의미하지 않음.
- 영양값의 포장 전체/1회 제공량 단위에 대한 라벨 대조. 기존 파서의 제품별 영양값을 1개당으로 해석하되 원라벨 검증 대기.
- 유형 분류는 원자료 그대로이며 큰컵 간짬뽕의 국물형 표기 등 재확인 필요. 유형별 수치는 잠정 탐색값.
- 40종은 사전 선택 목록이며 무작위 표본이나 시장 전체를 대표하지 않음.
- 영양 14종 중 중량 보유는 삼양 6종뿐. 중량 보정은 이 6종에만 가능. 가격 이상치 제외 시 5종.
- 기존 282건 후보 수와 원본 202행의 차이 및 중간 단계별 탈락 수는 재현할 로그가 부족함.
