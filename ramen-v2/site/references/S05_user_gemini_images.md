# S05 · 사용자 제공 Gemini 이미지

확인일: 2026-10-16. 생성 경로: 사용자가 Gemini에서 직접 생성하여 제공. 정확한 모델명·생성시각은 미확인. 이번 작업은 API를 호출하지 않았다.

| 원본 | 직접 열람한 내용 | 발표 적용 |
|---|---|---|
| ramen-v2/1.png | 컵라면 한 개·젓가락·왼쪽 여백 | S1 표지 · nano-cover-hero.png |
| ramen-v2/2.png | 컵라면 한 개·젓가락·왼쪽 여백 | 미사용·원본 보존 |
| ramen-v2/3.png | 편의점 컵라면 진열대 | S2 · nano-problem-shelf.png |
| ramen-v2/4.png | 크기가 다른 국물 컵라면 두 개 | S6 · nano-size-comparison.png |
| ramen-v2/5.png | 컵라면 한 개·젓가락·왼쪽 여백 | S12 결론 · nano-closing.png |

5개 모두 실제 PNG, RGBA, 2752×1536. PNG 사본은 변환 없이 바이트 그대로 복사했고 원본5개는 보존했다. 각 원본과 사본의 SHA-256 및 적용 기록은 `ramen-v2/assets/generated/image-manifest.json`에 있다.

번호와 내용이 달라 사용자에게 알리고 선택 질문을 보냈다. 응답 전 작업은 내용 기준으로 진행했다. 국물형·볶음형을 함께 보여주는 사진이 없어 S9는 개념 삽화를 유지했다. 없는 사진을 생성하거나 잘못된 사진을 실제 유형 비교로 표시하지 않았다.

사진 표시: “AI 생성 개념 사진 · 실제 상품 사진 아님”. 실제 분석 제품이나 정확한 중량비의 근거가 아니다. `generation-manifest.json`은 이전 API 실패 기록이며 이 사진의 생성 모델·시각을 나타내지 않는다. 로컬 검토까지 진행하고 공개 업로드·배포는 하지 않는다.
